# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。ticket_type仅接受普通/学生/老年（参数ticket_rates可追加票种与[0,1]折扣），空值与未登记票种在票价阶段隔离。票价F1至2026-11-01前为2元，F2为2.50元；票种实付=普通票价×票种折扣，学生0.50、老年0.20，按分四舍五入。

跨线路换乘必须在上一次实际付费行程后60分钟内，恰好60分钟排除。同线路无优惠；零付费行程不能延长换乘锚点。基数裁决见RULING.md：换乘权益与日封顶按**普通票价统一基数**测算，保证学生老年权益不缩水；乘客应收与清分补贴按**票种实付统一基数**收钱，换乘减免=min(票种实付, 权益)，从根上杜绝减免超过本程实付。先换乘减免、再日封顶，每张卡每个业务日形成唯一应收day_paid，并平行登记票种实付基数的影子应收alt_expected用于差异比对。每条票种实付=实算应收+换乘减免+封顶减免；每条普通票价=应收+票种让利+优惠补贴，优惠补贴≤票种实付。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
